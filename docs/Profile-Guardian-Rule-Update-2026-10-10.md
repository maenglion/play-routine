# 프로필·보호자·부모 규칙 등록 업데이트

## 구현 범위

### 프로필 사진
- 자녀는 상단 프로필 또는 프로필 메뉴에서 사진을 선택한다. 부모도 연결된 자녀 카드의 사진을 바꿀 수 있다.
- JPG/PNG/WebP 원본 최대 15MB. 사진 이동·확대 후 정사각형 영역을 선택한다.
- 브라우저에서 **256×256 WebP·64KiB 이하**로 압축하며, 서버도 실제 이미지 디코딩·자동 회전·메타데이터 제거·동일 크기 재압축을 수행한다.
- 원본 파일은 저장하지 않는다. DB에는 작은 파일의 저장소 key/URL만 기록한다.
- 서버는 Supabase 사용자 검증 후 활성 가족·본인 자녀 또는 같은 가족 부모 권한을 확인한다. 보호자/다른 가족/정지 계정은 업로드할 수 없다.
- 저장소는 업로드마다 고유 파일 key를 발급한다. 이전 파일 자동 삭제 정책은 아직 구현하지 않았다.

### 심볼과 그림자
- 사용자 제공 `Subtract_amount.svg`를 하얀 티켓 레이어로 적용했다. 외곽 컨테이너에는 box-shadow/filter가 없다. 하얀 SVG 내부 필터만 종이 그림자를 담당한다.
- `artifact_today.svg`는 오늘 적립 예정, `artifact_amount.svg`는 현재 보유량에 사용했다.
- 프로필은 제공 심볼의 검은 캡슐 형태를 재현하되 예시 인물 사진을 쓰지 않고 실제 등록 사진을 보여준다.
- 하단 바는 플로팅 유지. 알림 아이콘은 표시만 하며 비활성 상태다. 알림 목록은 이번 범위에 없다.

### 다중 보호자
- 부모 화면에서 이메일별 보호자 초대를 추가한다. 자녀 초대와 별도 테이블·생명주기이다.
- 보호자는 로그인 화면의 **보호자 → 첫 연결**에서 같은 이메일의 확인 링크를 요청하고, 비밀번호 설정 후 보호자 초대를 수락한다.
- 초대 생성 자체는 메일을 보내지 않으며 화면에 다음 단계를 명시한다.
- 활성 보호자는 상태 전용 RPC로 가족명과 연결된 자녀 이름·사진·연결 상태만 조회한다. 규칙·기록·CSV·프로필 변경과 다른 가족 접근을 차단한다.
- 원장이 없으므로 점수/보상 잔액을 임의로 만들어 반환하지 않는다. 현재 보호자 상태창의 점수는 미제공이다.
- DB에 소유 부모 전용 권한 회수 RPC를 준비했지만 회수 UI는 이번 범위에 포함하지 않았다.

### 부모 규칙 등록
- 매일 공부 / 스페셜 일정 / 생활 습관 / 기타를 입력한다. 약 복용은 평가·보상 규칙과 분리한다.
- 이름·부모 확인 기준·0~100 점수축·하한·보상 경계·시간 효과를 입력해 **초안 저장 → 내일부터 게시**한다.
- 이번 입력 모델은 퍼센트 또는 0~100으로 정규화한 수량 점수이다. 임의 단위의 무제한 원시 수량·다차원 평가·일정/자녀 배정은 후속 구현이다.
- 세 구간은 `[0, 하한)`, `[하한, 보상기준)`, `[보상기준, 100]`. 중립 구간을 빠뜨리지 않으며 상단 100을 포함한다.
- 보상·패널티 각각 0분이면 해당 효과 없음이다. 초기 패널티 기본값 0, 현재 입력 범위 각 0~240분. 전액몰수·음수 효과량을 지원하지 않는다.
- 부모 확인 미완료는 hold이고 패널티 확정이 아니다.
- 같은 이름·분류의 활동은 기존 ref/template을 재사용하며 새 버전 초안을 만든다. 게시된 버전은 불변이다.
- 게시 효력은 가족 시간대 기준 다음 날이다. 운영 조회는 오늘 유효한 활동별 최신 버전 하나만 반환해 중복 평가 원인을 차단한다.
- **지금은 등록 DB와 화면까지다. 자녀 할 일 배정·today·실제 평가·정산·원장·잔차는 아직 연결하지 않았다.** 등록만으로 티켓 잔액은 변하지 않는다.

## 검증 결과

- 브라우저 크롭 테스트: 256×256 WebP, 테스트 이미지 1,834 bytes. 실제 계정 업로드가 아닌 개발 미리보기 응답 검사이다.
- 서버 압축·가짜 이미지 거절·크롭 경계 자동시험 통과.
- 실제 PostgreSQL에서 보호자 초대/정확한 이메일 수락/직접 조회·수정 차단 검증 통과.
- 규칙 초안·게시·내일 효력·0분 정책 유지·동일 활동 새 버전·최신 유효 버전·보호자/다른 계정 차단 **20개 검사 통과**.
- 사진 편집 소유권·타 가족·보호자·정지 계정 **7개 검사 통과**.
- 모든 DB 시험 fixture는 롤백했다. 실제 부모·자녀 가족 연결은 보존했다.
- 적용 migration: 0006 보호자, 0007 규칙 등록, 0008 게시 함수 컬럼 별칭 보정. 기존 적용 migration은 수정하지 않았다.
