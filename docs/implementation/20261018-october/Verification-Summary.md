## 시험이 보증하지 않는 것

2연결 시험은 실제 PostgreSQL 잠금 직렬화다. 다중 commit 지급 경쟁/자동 송금/물리쿠폰 소비·회수/모든네트워크장애의 exactly-once 처리를 시험한 것으로 표시하지 않는다. 이번 시험이 새 부모·자녀 이메일 OTP 발송을 다시 수행한 것도 아니다. 기존 실제 이메일 연결과 Auth/RLS 회귀를 유지했다.

시행 규칙 설치와 19개의 미확인 자리표시 행은 아이가 실제 수행했다는 판정이 아니다. 확인·보상 발행·앱 밖 이행은 실제 부모 운영이 시작될 때 별도 기록된다. 최종 읽기 확인에서 권리0·이행0이었고, 관리자 seed 감사81개는 실제 설치 이력이다. 감사의 DATABASE_SESSION은 부모 웹 클릭으로 위장하지 않는다.
